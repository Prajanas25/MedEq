# MedEQ dependencies
# ---------------------------------------------------------------------------
# WHY THESE ARE PINNED (they used to be bare package names):
# The trained models in models/ are Python pickles, and a pickle is coupled to
# the library version that wrote it. The shipped models were re-serialised
# under exactly the versions below, so they load with NO warnings. With
# unpinned versions, pip installs whatever is newest that day and you get
#   "InconsistentVersionWarning: Trying to unpickle estimator LabelEncoder
#    from version X when using version Y"
# which is unsupported and can silently change behaviour.
#
# If you upgrade any of the first four lines, re-run:
#   python src/train_model.py
# so the saved models are rewritten by the version you are actually using.
# ---------------------------------------------------------------------------
